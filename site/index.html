How it works

Four stages, each built on the one before. Python, Pydantic, a free OpenRouter model, tool calling and Streamlit, built with Claude Code.

1. Urgency rulesThree tags, four fix paths, and a hidden rule: any brake, pedal or steering symptom is safety urgent, even with no alert and a calm tone.
2. ClassifyA free model tags all 300 messages. Pydantic checks every answer, and the rules can only raise a tag. 294 of 300 agree.
3. Book slotsThe model books through a tool that enforces the slot rules. No bay goes to a lower tag while a safety car waits.
4. Queue pageSafety on top, a paste box for new messages, a call list, and a warning when bays run out.
The calm one goes first. MSG-10309 is a thank-you note about a road trip, with no alert code and "no rush at all". It mentions the pedal going further down than it used to. It's tagged safety urgent: tow to service center, Thu 19 Nov 09:00, ahead of every angry wiper and touchscreen message.
